# E-Commerce Order & Inventory Management System

A Java-based E-Commerce Management System developed using Advanced Core Java concepts.

## Technologies Used

- Java 26
- Object-Oriented Programming
- Java Collections Framework
- Exception Handling
- Interfaces
- Inheritance
- Multithreading
- Java Swing
- File Handling
- Git & GitHub

## Main Modules

- Customer Management
- Product Management
- Inventory Management
- Shopping Cart
- Order Management
- Payment Management
- Delivery Management
- Notification System
- Reporting
- Administration
